# 残影材质与预览 · v5.7

打开 `Tools > Sandevistan...` 的“材质预览”页，读取已安装人物、残影部件或 Ghost.mat。左侧直接编辑实际材质，支持 Ctrl+Z；右侧使用私有预览场景和临时材质，不移动人物、不修改 FX。

## 统一修改全部材质

人物使用多张残影材质时，先选择人物根节点或某个残影部件，再点“读取选中对象”。“编辑范围”默认选择“全部残影材质 · N 个”，左侧同时修改该安装的所有独立颜色材质，包括其他快照与当前隐藏的衣服、道具。共享材质只计一次；其他人物的独立材质不参与。数值不同的设置显示混合状态，只有实际调整的项目会被统一。

调整后点“保存全部材质修改”，会同步并保存全部颜色材质及其 Depth / Cleanup 辅助材质，避免退出重开后只有一部分变化。批量编辑保留每个部件自己的原主贴图、UV 平铺/偏移、原主色、原贴图裁切和轮廓遮罩；这些源贴图字段在批量模式只读。额外“表面纹理”属于残影效果，可统一修改。

如果已经单独调好某张材质，选择它作为“当前参考材质”，点击“将当前材质效果应用到全部（保留原贴图）”，可统一不透明度、亮度、渐变强度、菲涅尔、网纹、额外表面纹理及其设置；随后保存全部。此操作支持一次 Ctrl+Z 撤销，FX 控制的年龄、可见度、配色索引和本人标记保持独立。希望只微调头发或衣服时，切换“仅当前材质”。只拖入一张 .mat 而未读取人物时仍只编辑该材质，需要读取安装后的对象才能确定批量范围。

常用面板显示材质模式、亮度与菲涅尔、不透明度、发光线纹和表面纹理。接入图片后才显示纹理强度和 Tiling；纹理细项、经典渐变自定义和 Stencil 冲突设置放在折叠项中。

## 原贴图渐变半透

在安装页选择“原网格＋原主色贴图 · 不减面”，会生成 `Ghost_Source_XX.mat`，每种原材质分别保留主色贴图及 UV 平铺、偏移和颜色。它与额外的“表面纹理”是两种用途：原主图沿原 UV 显示人物图案，表面纹理继续使用空间投影，可叠加自己的图片。

- 渐变染色强度：范围 0–1，默认 1 保持旧材质外观；0 关闭年龄渐变染色、保留原主贴图颜色，1 使用完整染色，中间值混合两种结果。觉得染色太深可先试 0.3–0.6；菲涅尔的渐变色也随之减弱，仍可通过 HDR 发光颜色着色。不透明度、亮度、网纹和额外表面纹理独立生效。
- 主贴图细节强度：默认 1，设为 0 去掉主贴图的颜色与明暗细节，改为均匀底色；底色仍受渐变染色强度控制，网格和贴图引用不变。
- 原色保留：默认 0.1，控制完整染色结果里使用多少原色；0 按贴图明暗染成渐变色，1 将原图颜色乘上渐变。它与“渐变染色强度”分开，关闭渐变应调整后者。
- 不透明度：该模式默认 0.4，背景可透出；前后表面继续使用统一的深度与防叠色处理。
- 细密网纹：默认强度 0.4、每米 90 格、线宽占单元 0.14；它调节底色明暗，独立于默认关闭的发光线纹。强度 0 可关闭，密度越高图案越细，远处会逐渐转为平均覆盖以减少摩尔纹。
- 菲涅尔：该模式默认强度 1.5，保留明亮轮廓，亮度和 HDR 颜色仍可自定义。

原主图的 Alpha 仅在源材质为裁切/透明时使用，避免不透明材质内未使用的 Alpha 错误隐藏身体。主图 Alpha 与 Cutoff 会同步到深度和清理材质，PNG 洞不会留下不可见遮挡。特殊 Shader 的额外图层、独立透明遮罩、材质换图和动态顶点特效需要手工处理；本功能不会复制原 Shader 的完整外观。

原网格不使用 8000 面目标。已有减面代理可在安装页切换模式后点“更新并替换安装”，取得完整几何和原 UV；材质面板不能还原减掉的面。更新会按源材质迁移透明度、渐变、发光和额外纹理等效果，同时重新生成网格相关的原贴图与裁切。BlendShape 权重仍是安装时形态，运行中的面捕变化不会复制到残影。

已有 v5.6 原网格安装直接导入 v5.6.1 即可使用染色滑块，无需重新安装人物或生成网格。进入“材质预览”，选择对应 `Ghost_Source_XX.mat`，在“材质方案”中调整；也可直接选中该材质，在 Inspector 中调整。各部件材质独立保存，可多选同类材质统一修改。该滑块是材质设置，不增加游戏同步参数。

## 本人视野保护

默认开启。自身相机进入残影时，“完全隐藏距离”以内的片段不显示，在“恢复显示距离”之外恢复原外观；默认分别为 0.65 米和 1 米，按世界米数计算。增大前者可减少后退时的头发/面部闪现，后者至少比前者大 0.01 米，形成过渡区。可关闭此功能以保留所有近处残影。

只影响本人普通相机，旁观者不受影响；VRChat 镜子与手持/拍照相机依靠相机标记保留完整效果。没有这些标记的世界自定义相机可能仍受距离保护。不能精确识别普通相机的第一/第三人称模式。

右侧“预览本人近处保护”只对临时预览材质模拟本人标记，滚轮接近模型可检查保护范围；不勾选时显示旁观者效果，不修改源材质的内部标记。深度、颜色和清理同时裁切，避免不可见的近处片段继续遮挡。单通道立体渲染使用双眼中心，其他模式使用当前相机，仍需真实头显复核舒适度。

本人标记由 v5.5 起的 FX 自动管理，尚未生成此层的旧安装可点击“更新并替换安装”，自动迁移材质效果。保护距离与开关不属于游戏同步菜单，也不增加同步参数。

## 两种方案

纯色轮廓（默认）：填充颜色均匀，边缘有菲涅尔发光。

细节明暗：根据法线和视线方向的柔和照明表现五官、头发与衣褶，并叠加菲涅尔发光。它仍保留深度和防重复叠色，不依赖重复网格混色。

两种模式安装默认每道均为 8000 三角面，指全部选中部件的合计；切换模式保留手动设置的面数。在材质检查器切换方案不会修改网格。“表面明暗强度”仅用于细节方案，菲涅尔控制对两种方案均有效。

## 菲涅尔与 HDR 亮度

- 整体亮度：默认 1，范围 0–8，同时乘在填充和菲涅尔发光上，对七套渐变均有效。
- 发光颜色：HDR 色框，默认白色，乘上当前年龄渐变；原贴图模式会按“渐变染色强度”从白色混合到渐变色，再乘 HDR 颜色。可在颜色窗口增加曝光，保留高于 1 的亮度。若希望保留渐变色相，可保持白色只提高 HDR 强度。
- 菲涅尔发光强度：默认 2，范围 0–10，设为 0 关闭边缘发光。
- 菲涅尔收紧：默认 3，数值越大亮边越窄，越小越宽。

菲涅尔只改变亮度，不改变半透明覆盖。旧的“边缘额外覆盖”和抖动透明设置已移除。

经典渐变的三个颜色同样使用 HDR 色框；其他六套使用内置渐变，可通过整体亮度与发光 HDR 色框增亮。HDR 颜色的 Alpha 不接管透明度，透明度继续由半透和纹理设置控制。

菲涅尔是视角相关的表面发亮，不需要场景光照。轮廓外扩散的光晕需要所在世界的 HDR/Bloom 后处理支持，单独设置 HDR 颜色不会自动创建 Bloom，也不会让模型照亮周围场景。

“应用半透与发光默认值”保留纹理和当前材质模式，重设透明、菲涅尔、亮度与排序设置。已有材质沿用此前保存的边缘强度；可用此按钮启用新版默认发光，无需重建人物网格。

## 发光线纹

旧扫描线已替换为“关闭 / 蜂巢 / 十字网格 / 方格”选择，默认关闭。两种材质模式均可手动开启，不需要纹理图片，也不需要重新安装人物。

新建材质、新安装资产与“应用半透与发光默认值”均关闭线纹。已保存材质中的图案选择继续保留；如需关闭，在“材质预览 → 发光线纹 → 图案”选择“关闭”。

- 线条颜色：独立 HDR 颜色，默认青色，不乘上填充的年龄渐变；适合让图案与底色清楚区分。
- 线条亮度：默认 3，可调 0–12，增加时输出高于 1 的亮度；整体亮度仍同时影响填充、菲涅尔和线纹。
- 图案密度：默认 12 个单元/米，可调 2–40，越大越密。
- 线条粗细：默认占单元宽度 0.05，可调 0.01–0.15；线边只做屏幕像素抗锯齿，不添加模糊光晕。

图案使用空间主轴投影，在曲面上可能有投影方向接缝。它保留统一的渐隐、不透明度、轮廓图集和图片 Alpha 裁切，后侧图案不会透到前面。线纹与自有纹理可同时使用，图片 RGB 调节填充，线纹保留独立线色。模式设为“关闭”或亮度为 0 时跳过线纹计算，不增加材质槽、额外绘制、图片资源或同步参数。

## 自己的纹理

把图片拖入“表面纹理”，会自动打开纹理强度。默认继续保留年龄渐变；“图片原色”可乘上图片颜色。

- 不透明度：0 全透明、1 不透明，默认 0.35。旧的整体透明度与填充密度在这里合并显示，读取原来两者的乘积，调整时继续保留相同的透明效果。
- Tiling：每米重复次数；数值越大图案越小。Offset 调整位置。
- 滚动速度：X/Y 为每秒平移的纹理重复次数。
- 图片 Alpha：PNG 透明区域影响残影；没有 Alpha 的黑底图片可开启“黑色透明”。
- 纹理强度设为 0 可关闭图案而保留已接入的图片。

“纹理选项”包含滚动速度、图片原色、Alpha 影响和亮度遮罩。移除图片会自动把纹理强度设为 0。

自定义图案用世界空间三平面投射，不依赖轮廓图集 UV。重复图案建议图片 Wrap Mode 设为 Repeat。不同表面方向的采样不同；纯色方案接入花纹后也会出现对应图案与明暗。

工具生成的轮廓 Alpha 图集负责头发等部件的裁切，由工具管理，不显示为可编辑的材质设置。可见度、年龄和渐变索引由 FX 控制，预览时使用右侧的年龄和渐变控件。

## 预览

没有指定部件时显示球体并忽略人物轮廓图集；指定 SMR 部件时显示该部件的当前姿态。年龄、渐变、播放开关只用于预览，游戏中由 FX 和菜单接管。拖动旋转、滚轮缩放，可更改预览背景。

选中安装后的 Snapshot 部件时，可开启“预览整道残影 · 当前穿搭”，将同一道的可见衣服、头发和身体一起显示；批量模式的“当前参考材质”决定一键应用的来源，单独模式的“编辑部件材质”决定编辑对象。隐藏穿搭只在预览时按源部件开关过滤，仍参与全部材质的编辑和保存；当前选中部件可单独检查。左侧改实际材质，右侧的年龄、曝光、本人保护和整道预览只影响临时预览。

对比两种方案时，先保持相同年龄、渐变与菲涅尔设置。纯色方案均匀填充；细节方案增加表面起伏。两种方案都能透出背景，背景不同会使最终混合颜色不同。

右侧“预览曝光（EV）”只改变临时预览亮度，不写回实际材质，默认 0。HDR 亮部过白时可调到 -1 或 -2 检查色彩与边缘；此预览不附带 Bloom，最终光晕以所在世界为准。

## 面数与残影数对性能的影响

每道面数越高，几何与蒙皮开销越大；最大残影数越多，预建的网格、骨骼和约束越多。每道 8000 面时，容量 3 约增加 24000 面，容量 10 约增加 80000 面，不含原人物。数量轮盘只减少当前活跃绘制，不删除预建池；降低安装容量或每道面数才会减少这部分资产和 SDK 统计。

上述 8000 面默认值属于减面代理的两种材质。原网格模式保留原部件总面数，例如每道 8 万面、容量 3 就额外约 24 万面；其材质组、完整骨骼和缩放约束也要计入预算。原贴图直接复用资产，不代表额外的纹理采样、蒙皮或绘制免费。上传仍仅适用于 PC，以完整人物的 SDK 检查为准。

修改材质后工具会同步 Depth、Cleanup 辅助材质，构建前也会同步。双面和深度写入状态由 Shader 固定处理；排序与实例化开关不再作为材质调节项。防叠色使用 Stencil 位 16，可在“高级 · 与其他特效的遮挡冲突”换位，或 Off 关闭；与其他 Stencil 特效共用同一位可能冲突。关闭后共面叠色可能出现。透明排序限制和最终上传预算见 README。
