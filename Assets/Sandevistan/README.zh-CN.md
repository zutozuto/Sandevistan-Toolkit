# 斯安威斯坦 · PC Avatar 工具 v5.7

唯一入口：`Tools > Sandevistan...`。窗口包含“安装 / 移动测试 / 材质预览”三个页签。需要 Unity 2022.3、VRChat Avatars PC SDK、Modular Avatar 与 NDMF。

## 安装

选择带有效 Humanoid Animator 的人物根节点，打开工具并读取选中人物。勾选所有可能穿戴的网格，包括现在隐藏、以后会启用的衣服和道具。

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| 最大残影数 | 3，可设 3–10 | 真正只生成指定数量的池、冻结骨骼、约束和 Animator 层 |
| 网格与贴图 | 减面代理 | 新增“原网格＋原主色贴图 · 不减面”，保留原始几何和贴图细节 |
| 材质方案 | 纯色轮廓 | 均匀填充与菲涅尔发光；细节模式增加表面明暗 |
| 每道目标面数 | 两种模式均为 8000 | 全部勾选部件合计，实际受拓扑保护限制；可手动调整 |
| 菲涅尔发光 | 强度 2、收紧 3、HDR 白色 | 乘上当前渐变；两种模式均可自定义 |
| 整体亮度 | 1，可设 0–8 | 同时控制填充和边缘；HDR 颜色可进一步提高亮度 |
| 发光线纹 | 关闭，可手动选择蜂巢、十字网格或方格 | 独立 HDR 线条颜色与亮度，密度 12、粗细 0.05 |
| 间距轮盘上限 | 0.5 米 | 可编辑，至少 0.12 米；不再按身体大小自动放大 |
| 跑步触发速度 | 3.5 米/秒 | 仅跑步模式的落地速度门槛；应高于世界走路速度、低于跑步速度 |
| 本人视野保护 | 开启，0.65–1 米 | 普通相机附近的自身残影片段淡出；镜子、拍照相机和旁观者保留效果 |

两种材质默认每道均为 8000 三角面，切换方案保留手动设置的面数。两者都保留半透明、轮廓裁切、前后遮挡、防共面重复叠色、自定义纹理和菲涅尔发光。

点击“安装到人物”，生成独立资产与 `Sandevistan_A` 子物体。选中已安装的人物后，安装页会读取它的容量、目标面数、网格模式、材质方案、间距上限、跑步门槛和已选部件；改好设置后点击“更新并替换安装”即可。切换到另一人物会读取那个人物的配置，同一人物内选择部件不会重置尚未提交的修改。“刷新网格”保留已有勾选，新增部件需手动勾选。

更新先在临时根下生成新网格、骨骼、材质、FX 和 MA 菜单，全部成功后才替换旧根，最终只保留一套安装；失败或取消时保留旧安装。更新与首次安装均支持 Ctrl+Z，不自动保存场景，请保存人物场景或 Prefab 以持久保留安装配置。配置复用既有的编辑元数据组件，构建上传时移除，不增加运行脚本或同步参数。没有单独的旧版升级、修复或演示入口。

现有 v5.6.2 及更早安装没有完整配置记录，会从绑定部件、快照数量和 FX 恢复可读取的设置；旧版减面时的精确目标值不可恢复，面板会用当前每道实际面数估算并注明。更新一次后即可准确恢复今后填写的目标值。透明度、渐变染色、亮度、菲涅尔、网纹和额外纹理等材质效果会迁移到新材质，原贴图模式按源材质对应，新增部件沿用已有的一套效果。切换纯色/细节方案时尊重新选择；贴图与轮廓裁切根据新网格重新生成。

第一次生成会烘焙轮廓图集并减面；相同输入再次安装会复用缓存。缓存索引位于 Library，实际网格和图集在首次生成目录。删除仍被引用的旧生成资产会破坏这些引用。

## 原网格＋原主色贴图

安装页把“网格与贴图”改为“原网格＋原主色贴图 · 不减面”。此选项不使用 8000 面目标，不减面，也不删除透明或当前隐藏部件的三角面。每道保留全部勾选部件的几何、原 UV、骨骼权重（含超过四个影响）、绑定矩阵和 BlendShape 帧。为适配半透遮挡，会按原材质拆成独立部件，并转换到快照空间，因此生成资产与源网格并非同一个 Mesh 引用，但保留原始三角面形状和贴图坐标。

每个原材质直接复用自己的主贴图资产、平铺、偏移和主色，不做颜色图集，不另复制贴图。支持常见 `_MainTex` / `_Color` 和 `_BaseMap` / `_BaseColor`，包括仍保存这些属性的锁定材质。默认按原图明暗加少量原色，再乘菜单的年龄渐变，表现脸部、衣服和头发上的图案；源透明材质的主图 Alpha 与 Cutoff 同步到三个覆盖 Pass。原材质的额外色层、MatCap、法线贴图、特殊 UV 变换、顶点位移和独立 Alpha Mask 不会自动移植。

默认不透明度 0.4、菲涅尔强度 1.5，增加非发光的细密网纹（强度 0.4、每米 90 格、线宽 0.14），发光线纹仍关闭。材质预览左侧可以调“渐变染色强度”“主贴图细节强度”“原色保留”“细密网纹”和半透明。染色强度默认 1 保持原外观，0 保留原主贴图颜色，中间值混合；觉得染色太深可先试 0.3–0.6。菲涅尔的渐变随之减弱，HDR 发光颜色与不透明度独立控制。原网格保留全部源骨骼，额外使用官方缩放约束；快照冻结的是当时的骨骼姿态，不复制整套 PhysBone 模拟。

从 v5.6 更新到 v5.6.1，直接导入新版工具包即可调整上述染色强度，无需移除或重新安装 `Sandevistan_A`。在“材质预览 → 材质方案”或 `Ghost_Source_XX.mat` 的 Inspector 中修改；不同部件使用独立材质，可分别或多选调整。此项不增加同步参数、贴图采样或绘制次数。

v5.6.2 支持在材质预览中统一修改全部残影材质。先选人物根节点，点“读取选中对象”；编辑范围默认“全部残影材质”，涵盖该安装的全部快照和隐藏穿搭，并去重共享材质。调整不透明度、亮度、渐变强度、菲涅尔或纹理后，点“保存全部材质修改”，会一并保存所有颜色及 Depth / Cleanup 辅助材质。各部件自己的原主贴图、UV、原主色和裁切保持独立。已有单张调好的设置可用“将当前材质效果应用到全部（保留原贴图）”；也可切换“仅当前材质”微调。支持 Ctrl+Z，导入新版无需重新安装人物。

“完全一致”针对原始几何、UV 与主贴图，不表示动态复制原 Shader 或所有表情：BlendShape **权重使用安装时值**，之后的面捕、表情或 BlendShape 换装不会实时复制；骨骼驱动的动作和已勾选衣物的 GameObject / Renderer 开关继续跟随。材质换图、溶解、布料模拟和运行时换网格也不会自动镜像。

此模式按“原面数 × 安装容量”增加几何，源材质分组和全部骨骼也会增加 Renderer、三次绘制与约束。例如选中原部件共 8 万面，容量 3 额外约 24 万面，容量 10 额外约 80 万面，不含本体。安装页会显示面数、材质槽与约束估计；建议从容量 3 和必要部件开始，以完整人物构建后的 SDK 评级、限制及 Build & Test 为准。上传仍不含自定义运行脚本，菜单同步预算仍为 35 bits。

已有安装可在安装页切换网格模式，再点击“更新并替换安装”，生成原网格与多张主贴图材质；仅切换旧材质不能恢复已经减掉的几何和原 UV。旧生成目录和自定义材质保留，供撤销、缓存及其他人物引用使用；没有引用的旧资产不会随当前人物上传。

## VRChat 菜单

默认关闭。开启后持续移动才会生成历史姿态残影，停下后逐渐消失。

- 触发方式：默认“一直触发 · 移动时”，走路和跑步都生成，站立仍停发；“仅跑步时触发”在地面超过跑步速度门槛时开始生成，跑步后起跳会在空中延续，落地后低于门槛的 90% 才停发。已有残影按存留时间自然淡出。速度门槛在安装页设置，默认 3.5 米/秒；例如默认门槛的停止速度为 3.15 米/秒，留出余量避免临界速度反复切换。总开关关闭会立即清除跑步资格，空中重新开启要等落地达到门槛才能再次取得资格。
- 数量轮盘：3 到安装上限；容量为 3 时固定为 3，不额外生成隐藏池。
- 间距轮盘：0.12 米到安装时填写的上限，默认最高 0.5 米。默认实际间距 0.2 米（不超出上限）。按 VelocityMagnitude 积分估算距离，不是路径碰撞检测。
- 存留轮盘：0.2–2 秒。满池时会提前复用最旧的残影，因此高速、小间距时实际可见时间可能短于设定值。
- 七种渐变配色：按钮选择渐变种类，残影随年龄变化颜色。

0.5 米间距可能与相邻残影重叠，这与可编辑间距的设定相符。若希望完全分离，可以手动把安装上限调大。实际移动距离受帧率和远端速度估计影响；房间内现实走动未必更新 VelocityMagnitude。

Avatar 无法直接读取 PC 的 Shift 键，也没有官方 Sprint 参数。仅跑步模式由本人的官方 VelocityMagnitude 与 Grounded 参数判断速度并同步一个 Bool，旁观者使用这个结果，避免远端速度估计在跑步门槛附近误判。PC 的 Shift 加速、VR 摇杆跑步均可触发，但世界会修改走路/跑步速度；默认 3.5 米/秒不能保证区分所有世界，移动平台等造成的落地高速也可能触发。v5.5.1 修复跑跳中断：只在地面启动和按速度停止，空中继承起跳前的跑步资格，因此走路或原地起跳不会单凭垂直速度启动。空中速度暂时降为零时仍停发，但不丢失资格，恢复移动后可继续生成，落地后重新按门槛判断。

导入工具包只更新生成器，已有的 FX 和菜单不会自动重写。需要跑跳修复时，在安装页读取已安装人物，再点“更新并替换安装”；工具会迁移材质效果并重新生成 FX。旧生成目录保留，供撤销和其他资产引用。

## 测试与预览

移动测试：进入 Play，启动 Gesture Manager 模拟，在移动测试页读取正在模拟的人物。开始控制后 WASD 移动、空格跳跃、Shift 加速，Esc 停止。切换工具页签会停止控制；关闭工具会停止移动并恢复工具自动开启的残影状态。只有编辑器逻辑，不向 Avatar 添加移动脚本。

测试仅跑步模式时，在菜单中选择该模式。移动测试默认走路 3 米/秒、Shift 6 米/秒，配合默认 3.5 米/秒门槛，WASD 走路不生成，Shift + WASD 跑步才生成。自动开启残影只控制总开关，不更改你选择的触发方式。

材质预览：读取已安装的人物、某个残影片段或 Ghost.mat。左侧修改实际材质，右侧临时强制显示。可预览年龄、渐变、纹理、纯色/细节和菲涅尔；拖动旋转，滚轮缩放。右侧“预览曝光”可调低以检查 HDR 亮部，不修改实际材质。切换材质方案只改变着色，不会在预览中改变网格面数。详见 `Material-guide.zh-CN.md`。

HDR 颜色适合控制发光：Shader 保留高于 1 的 RGB，整体亮度影响七套渐变，菲涅尔颜色乘上当前渐变。增亮不改变透明度和前后遮挡。轮廓外扩散的光晕依赖所在世界的 Bloom 后处理；材质预览不附带 Bloom，Avatar 不添加上传相机或后处理组件。

材质常用设置为模式、菲涅尔、亮度、不透明度、发光线纹和表面纹理。两个透明度控件合成一个，保留旧材质的有效透明度；纹理细项折叠显示。旧扫描线改为蜂巢、十字网格和方格，支持独立 HDR 线色、亮度、密度与粗细；无需图片，可与自己的纹理叠加。旧抖动透明与额外边缘覆盖已移除，双面和深度状态固定由 Shader 处理。轮廓图集与 FX 参数由工具管理。

## 本人视野保护

后退时，本人相机容易走进刚冻结的残影，看到头发、脸和身体内侧。v5.5 使用内置 IsLocal 在 FX 中标记本人，在 Shader 内按当前相机距离逐片段隐藏：默认 0.65 米内完全不可见，0.65–1 米平滑恢复，超过 1 米保留原效果。只改变本机绘制，不停止生成或同步残影，旁观者可见完整轨迹。单通道立体渲染使用双眼中心，其他模式使用当前相机位置。

材质预览左侧“本人视野保护”可开启/关闭并调整两项世界米数距离；右侧勾选“预览本人近处保护”并滚轮接近模型，可检查淡出，默认按旁观者预览。三种 Pass 使用相同保护规则，完全隐藏的片段不写入遮挡深度或 Stencil。

VRChat 镜子与拍照/手持相机通过相机全局标记跳过保护，保留完整残影。普通世界自定义相机若不提供这些标记，仍会按距离保护；这里并非精确识别第一/第三人称，自己的普通第三人称相机接近残影时也会淡出。头像尺寸变化很大时可调整保护距离。Shader 只做渲染裁切，不删除网格、骨骼或约束，不能据此减少 SDK 评级统计。

尚无本人视野保护层的旧安装可点“更新并替换安装”，以生成驱动 _IsLocalAvatar 的新 FX 层并保留材质效果；仅导入新版 Shader 无法给旧 FX 增加本人识别。若复用旧 Ghost.mat，请通过材质检查器同步其深度/清理材质。新增一个本地视野 Animator 层，仍是 35 bits 同步参数，无新增网格、约束、材质槽或运行脚本。未实测真实客户端镜子、远端和头显双眼，以 SDK Build & Test 为最终确认。

## 性能与换装

每道面数越高，几何处理和蒙皮负担越大。最大残影数越多，实际预建的网格、冻结骨骼、约束和动画层越多；额外预建面数约为“每道面数 × 安装容量”。例如每道 8000 面，容量 3 约增加 24000 面，容量 10 约增加 80000 面，均不包含原人物。特殊拓扑可能高于目标，以安装报告为准。

运行时数量轮盘调低可减少活跃绘制，但不会删除隐藏池或减少它们在 SDK 中的统计。若要降低预建开销和评级统计，应在安装页减少最大残影数或每道面数。实际帧率还受可见部件数、屏幕覆盖面积、透明绘制和其他 Avatar 内容影响，不能只用面数估算。

构建时按相同显隐、材质、骨骼和动画条件合并网格。不同衣装开关会分别保留，跟随 GameObject 与 Renderer.enabled。材质溶解、BlendShape 隐藏、运行时换网格不会自动镜像。不会按当前摄像机或当前隐藏穿搭永久删除身体和衣物。若另一插件先删除源 Renderer，应把这些源部件排除出那个插件的网格合并。

SMR 和官方冻结骨骼约束用于保留过去的姿态。无自定义运行脚本、上传相机或 GrabPass；编辑元数据构建后移除。6 个菜单控制参数加 1 个内部跑步状态，共 35 bits（比 v5.3 多 2 bits）；新增一个本地跑步判定 Animator 层，不增加网格、材质槽或约束。最终总预算、评级、包体和显存以完整人物经 MA 构建后的 SDK 为准。

每组合并网格使用三个单 Pass 材质槽：Depth 3090、Ghost 3100、Cleanup 3101，共用一份几何。默认 Stencil 位 16；其他特效占用同一位时可换位或 Off。清理只处理此位，不恢复其他特效原本在此位的数据。后画的透明玻璃和粒子可能受深度排序影响。未验证真实 VRChat 远端和头显双眼。

Depth 和 Cleanup 仅保留裁切、纹理透明和覆盖设置，不计算颜色、菲涅尔、发光线纹或表面明暗，也不生成细节着色变体。线纹在主颜色 Pass 中生成，关闭时跳过计算；纹理不影响透明度时，辅助 Pass 跳过表面图案采样。绘制次数仍为每组合并网格三次。

## 其他工程导入

新版包只包含工具、Shader 和两份说明。若其他工程还保留旧版本，先备份并移除旧 `Assets/Sandevistan` 工具目录，再导入新版，避免 Unity 导入包保留已经移除的旧脚本与菜单。保留 `Sandevistan_Installed` 和 `Sandevistan_Depth`，它们是人物已使用的资产。
